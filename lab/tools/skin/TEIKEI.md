# 道具づくりの 定型（アニメ工房・動画工房 と 同じ 作り）

新しい 便利ツールを 作る ときは、ここに そろえる。
見本は `lab/tools/anime-kobo/` と `lab/tools/douga-kobo/`。

## 見た目

- 色は 生成りの あたたかい 白が 基本
  - 下じき `--cream #FBFAEC` ／ カード `--paper #FFFEF7` ／ 文字 `--ink #1E1C14`
  - そえ書き `--ink2 #5C5843` ／ うすい しきり `--line #E8E5D0`
  - 強調は ライム `--main #E1DD60`
- 黒は 小さな アクセント だけ。背景や 広い 面に 黒を 使わない
- いちばん 上の 帯（`#top`）は 黄色 `#E1DD60`
- 見出しは 黒い まるピル
- 部品は 白い カード、まるみ 大きめ、かげは ほんの少し
- アイコンは Hugeicons
  - `../skin/icons.js` を 読むと 絵文字が Hugeicons に 置きかわる
  - 対応は `skin/icons.map.json`。足したら `skin/build-icons.mjs` で 作り直す
    （`npm i --no-save @hugeicons/core-free-icons` → `node build-icons.mjs` → `node_modules` と `package-lock.json` を 消す）
- css の 読む 順: `tokens.css` → `layout.css` → `parts.css` → `soft.css`（道具ごとの 色）。
  共通の かぶせは `../skin/soft.css`

## 画面の ならび

- 上: 黄色の 帯。左に 道具名・大きさ／長さ・画質、右に 全画面・音・もどす・やり直す・書き出す
- 左: 道具の はしら（アイコン＋短い 名前の カード）
- まん中: キャンバス
- 下: 再生バー → ボタン列（アイコンだけ。さわると 名前が 出る）→ タイムライン
  - タイムラインの 高さは 上の ふちの つまみで 変えられる（覚えて おく）
- 設定は 右から 出る シート。見出し → つまみ → 説明（`.empty`）の 順
- 知らせは 下の トースト（`toast()`）

## さわり心地（タブレット・スマホ）

- つまみ・バーは 触った だけでは 動かない。ドラッグした ぶんだけ（相対）、数 px 動くまで 何もしない
  （`lab/tools/oekaki-kobo/js/rslider.js`。`<input type="range">` を ぜんぶ 置きかえる）
- 2本指タップで もどす、3本指タップで やり直す。2回 走らない よう 500ms の まち
- 押す ところは 36px 以上
- ☑（まとめて えらぶ）・⠿（つまんで ならべかえ）・👁（表示）は 行の 中に かならず 入る

## 仕組み

- ES モジュール。中の import には ぜんぶ `?v=番号` を つける
  - 1つでも 番号が ずれると 同じ ファイルが 2回 読まれて こわれる。上げる ときは ぜんぶ いっしょに
  - `stamp.py` で そろえられる。`sw.js` の `VER` も 同じ 番号に
- サービスワーカーは「新しいのを 先に、つながらない ときだけ 手もと」
- 作品の 状態は 1つの 入れもの（`S.proj`）。絵の 中身は `assets`（data URL）、読みこんだ Image は 別に 持つ
- もどすは スナップショット方式
  - 1回で 終わる ものは `edit('名前', () => {...})`
  - つまみなど 続く ものは `beginEdit()` 〜 `commitEdit()`
- 変えたら `onChange()`。シートは 作り直される ので、つまみの 値は シートの 外（作品か モジュールの 変数）に 持つ
  - シートの 中で 写しを 作ると、作り直した とたん 古い ほうを 書きかえて 効かなく なる
- 自動で しまう（IndexedDB）。作品ファイル（.json）の 書き出し・読みこみも つける
- 読みこみは PSD（ag-psd）・PNG・JPEG・動画。PSD の グループは フォルダに する
- ホーム画面に 置ける（`manifest.webmanifest`・アイコン）

## 文章

- 画面の 字は ひらがな 多め、短く。わかち書き（ことばの あいだに すきま）
- コミットの 説明は 短く・地味に（CLAUDE.md の とおり）

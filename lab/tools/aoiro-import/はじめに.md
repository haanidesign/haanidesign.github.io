# レシート仕訳（ローカル版）

レシート・領収書・請求書の 写真や PDF を 読んで、
やよいの青色申告 オンライン に 取り込める CSV（弥生インポート形式）を 作る。
読み取りは このパソコンの 中の AI（Ollama）で やる。画像は 外に 出ない。

## 置き場所

`C:\ai\aoiro-import\`

## はじめの 準備（1回だけ）

`setup.bat` を ダブルクリック。やること:

1. このフォルダを `C:\ai\aoiro-import` に コピー
2. Ollama が 無ければ winget で 入れる
3. 画像が 読める モデル `qwen2.5vl:7b`（約6GB）を 落とす
4. デスクトップ（`C:\デスクトップ`）に「レシート仕訳」の ショートカットを 作る

別の モデルに したい とき: `setup.bat -Model qwen3-vl:8b` など。
RTX 4060 Ti 8GB なら 7〜8B の モデルが ちょうどいい。

## ふだんの 使い方

1. デスクトップの「レシート仕訳」（= `start.bat`）を 開く
   → Ollama を 起こして、ブラウザで http://localhost:8765/ が 開く
2. 設定で 屋号 と 消費税（免税/課税）を 入れる（最初だけ）
3. 写真か PDF を 入れる → 表を 見なおす
4. 「弥生用CSV」で 保存
5. やよいの青色申告 オンライン →「設定」→「弥生データのインポート」→ その CSV

はじめは 1〜2件だけ 取り込んで、科目と 税区分が 思った とおりか 確かめる。

## うまく いかない とき

- 「Ollama に つながりません」… `start.bat` から 開いたか。index.html を 直接 開くと 動かない
- 読み取りが 遅い … 1枚 20〜60秒くらいは かかる。1枚ずつ 順番に 読む
- 読み取りが あやしい … 設定の「読み取りAI」を Claude に すると 精度が 上がる（APIキーと ネットが 要る）

## ファイル

PSDはレイヤーごとに読みます。ベクターマスク（パス）を持つレイヤーはそのままベクターとして使い、絵で描かれたレイヤーは中心線を拾ってベクターに起こします。

2. 手のクセ

ゆらぎ・はみ出し・かんたん化・最短の線は、すべて「元の線の太さの何倍か」で効きます。絵の解像度が変わっても、見た目の強さは変わりません。

4. 色と書き出し

ボイルは、同じ絵をゆらぎ違いで複数枚出す機能です。3枚出してループさせると、止め絵がふるえる、あの感じになります。

PSDは、元のレイヤーの上に「手書き線」レイヤーを足して保存します。シェイプレイヤーにするとPhotoshopでパスとして編集できます（見た目用のピクセルも一緒に入るので、クリスタなど他のソフトでもそのまま見えます）。

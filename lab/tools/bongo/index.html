背景

キーを打つと、その位置に手が行く。

キーボードモード＝押したキーの横の位置で、左手・右手の行き先が決まる。左半分は左手、右半分は右手。
タブレットモード＝ステージの上でマウスを動かすとペン先がついてくる。押している間は下がる。
自分の絵＝ステージに画像をドロップ。まとめて落とすと、ファイル名でパーツに振り分ける。

自分の絵を入れる

透過PNG・GIF・WebP。ステージに直接ドロップしてもいい。
まとめて落とすときのファイル名の目印：
base / body（からだ）、lhand-up / lhand-down（左手）、 rhand-up / rhand-down（右手）、pen、desk / key。
目印がない名前は、上から空いているパーツに順に入る。

書き出す ときに、まわりの すき間を 切って、LINE の 大きさ(偶数・まわり 10px)に 自動で そろえます。

01Checkスタンプの 点検
02Info申請に 書く こと
03Export申請用の zip

中身: 01.png 〜 と main.png・tab.png。LINE の「ZIPファイルでアップロード」に そのまま 入れられます。

04Apply申請の しかた
  1. LINE Creators Market を 開いて、ログインする。
  2. 「新規登録」→ スタンプ を 選ぶ。
  3. 「表示情報」に、上の 02 の 文字を 貼る(コピーボタンが べんり)。
  4. 「スタンプ画像」で 数を 8 個に して、「ZIPファイルでアップロード」から 03 の zip を 入れる。
  5. 「販売情報」で 値段と 公開の しかたを 決めて 保存する。
  6. 「リクエスト」で 審査に 出す。ログインと この ボタンは、本人が 押して ください。

決まりは LINE の スタンプの ガイドライン と 動くスタンプの ガイドライン を もとに しています。
